## Setup Instructions

### 1. Import the Database
```bash
mysql -u root -p < schema.sql
```
This creates the `niceeat` database, all tables, and seed data (10 restaurants, 30 menu items, 1 demo user, 6 demo orders).

### 2. Adjust Connection String (if needed)
Edit [appsettings.json](file:///d:/Carlos/kuliah/OOP/NICE.EAT/appsettings.json):
```json
{
  "ConnectionStrings": {
    "DefaultConnection": "Server=localhost;Port=3306;Database=niceeat;Uid=root;Pwd=root;CharSet=utf8mb4;"
  }
}
```

### 3. Run the App
```bash
cd d:\Carlos\kuliah\OOP\NICE.EAT
dotnet run
```

## Features Implemented

| Feature | Implementation |
|---|---|
| Restaurant recommendation | Budget + spicy + vegan + mood filters via parameterized SQL |
| Mood-based filtering | [MoodMapper](file:///d:/Carlos/kuliah/OOP/NICE.EAT/Utilities/MoodMapper.cs#7-36) → `FIND_IN_SET()` in SQL |
| Wait time simulation | [WaitTimeService](file:///d:/Carlos/kuliah/OOP/NICE.EAT/Services/WaitTimeService.cs#7-30) using `Random.Shared` |
| Order history | JOIN query ordered newest-first |
| Favorite restaurant | `GROUP BY restaurant_id ORDER BY COUNT DESC` |
| Most popular menu | `GROUP BY menu_item_id` across all orders |
| Login / Register | Username lookup + `LAST_INSERT_ID()` insert |
| SQL injection prevention | 100% parameterized queries (`MySqlCommand.Parameters`) |
